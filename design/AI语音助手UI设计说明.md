### 阶段1：悬浮球与基础状态设计

**提示词1：创建极简悬浮球系统**

```
设计一个AI语音助手的极简悬浮球系统，包含以下状态：

1. 待机状态：
   - 16×16像素的灰色半透明圆形
   - 位于屏幕右下角
   - 有微弱的呼吸灯动画（3秒循环）

2. 激活聆听状态：
   - 变为蓝色圆形，直径扩大至24像素
   - 中心显示白色麦克风图标
   - 蓝色呼吸动画加快（1秒循环）

3. 处理状态：
   - 紫色圆形，24像素
   - 中心显示旋转加载图标
   - 下方显示一行文字：“处理中...”

4. 成功状态：
   - 绿色圆形，24像素
   - 白色对勾图标
   - 自动2秒后恢复待机状态

5. 错误状态：
   - 红色圆形，24像素
   - 白色感叹号图标
   - 保持显示直到用户交互

要求：所有状态圆形有轻微投影，透明度90%，无边框，毛玻璃模糊背景效果。
```

**提示词2：基础悬浮窗布局**

```
设计一个精简悬浮窗界面，尺寸为120×40像素，包含：

顶部区域：图标+状态文字
- 左侧：状态图标（麦克风/加载/对勾/错误）
- 右侧：状态描述文字，12号字体，如“聆听中”、“处理中”、“完成”

底部区域：语音转文字显示
- 用户语音实时转文字，最多显示8个字
- 13号字体，加粗
- 自动省略过长文字，用“...”表示

布局要求：
- 两行布局，间距紧凑
- 内边距：上下8px，左右12px
- 背景：半透明黑色(#000000) 90%不透明度，高斯模糊20px
- 圆角：12px
- 文字颜色：白色

示例内容：
第一行：🎤 聆听中
第二行：打开微信应用
```

### 阶段2：交互状态流程图

**提示词3：状态转换原型**

```
创建一个AI语音助手状态转换的交互流程图，包含5个界面：

界面1：待机态
- 屏幕右下角灰色小圆点
- 标注：呼吸灯动画，监听中

界面2：唤醒态
- 蓝色悬浮球，显示麦克风图标
- 文字：“说话中...”
- 标注：用户说出唤醒词

界面3：指令识别
- 悬浮窗展开为120×40px
- 第一行：🎤 你说：
- 第二行：“打开微信”
- 标注：实时语音转文字

界面4：执行中
- 悬浮窗紫色主题
- 第一行：⏳ 执行中
- 第二行：“打开微信”
- 标注：AI处理指令

界面5：完成
- 悬浮窗绿色主题
- 第一行：✅ 完成
- 第二行：（空白）
- 标注：2秒自动收起

用箭头连接状态转换，添加触发条件说明。
```
